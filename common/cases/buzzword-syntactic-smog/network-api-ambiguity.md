# Case: Buzzword Syntactic Smog (Network APIs)

## Original Text (Citizen Digital)
> "...demonstrations by Orange and Colt in 2025 showed applications requesting “quality on demand” and programming network behaviour in real time across mobile and fixed domains."
> (source: https://www.citizen.digital/article/opinion-what-to-watch-in-2026-mobile-transformation-n376327)

## Problem
- **Ambiguous Agency**: Who is "programming network behaviour"? Syntactically, it's the "applications," but logically, it's the network API or the developers. Equating an application's request with the act of "programming" creates a logical gap.
- **Scope Blur**: "Across mobile and fixed domains" is physically far from the subjects it modifies. It's unclear if it applies only to "network behaviour" or the entire demonstration scope.
- **Meaningless Concatenation**: The writer strings together technical terms without clear logical connectors, forcing the reader to "hallucinate" the technical architecture to make sense of the sentence.

## Refactored Text
> "...demonstrations by Orange and Colt in 2025 showcased how applications can use APIs to request 'quality on demand.' These tests proved that network behavior can now be programmed in real time across both mobile and fixed domains."

## Impact on AI/Reader
- **Human Reader**: Likely scans the words without truly grasping the mechanism, leading to a "vague feeling of progress" rather than actual understanding.
- **AI**: An AI extracting causal relationships might incorrectly label "Application" as the "Programmer of Networks," leading to an erroneous technical ontology.

## Gemini's Logic Audit
This is a "Dangling Participle of Logic." When writers use jargon they don't fully master, they tend to use present participles (-ing) as a "glue" to connect disparate concepts. This avoids defining the exact relationship (cause, effect, or tool), resulting in a low-information-density sentence that sounds impressive but lacks a clear logical kernel.
